# 泰熙爾札娜 珠寶切磨工坊

Three.js gem-faceting game. The playable site is `dist/` and deploys to GitHub Pages on every push to `main`.

- Play: https://vitokok-lab.github.io/gemstudio/
- Run locally: `cd dist && python3 -m http.server 8765`, then open http://localhost:8765/
- `blender/`: scripts that build the workshop models, studio HDRI and level thumbnails.
- Music credits: `dist/music/CREDITS.txt`.
